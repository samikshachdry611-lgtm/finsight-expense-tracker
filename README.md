# FinSight 💳

A personal **Expense & Budget Analytics Dashboard** with live Chart.js visualizations, local persistence, and one-click CSV report exports.

🔗 **Live Demo:** [View Live App](https://samikshachdry611-lgtm.github.io/finsight-expense-tracker/)

## ✨ Features
- Real-time balance, income, and expense calculations
- Interactive doughnut chart breaking down spending by category via **Chart.js**
- One-click **CSV Export** for spreadsheet reporting
- Automatic data persistence using `localStorage`
